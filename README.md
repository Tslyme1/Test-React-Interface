# Test React Interface

Прототип интерфейса для конусных дробилок КМД/КСД (Уралмаш), собранный в Claude Design.

## Состав

| Путь | Что это |
|---|---|
| `Дробилки КМД-КСД.dc.html` | Основной прототип интерфейса |
| `Canvas.dc.html` | Канвас проекта |
| `Storybook.dc.html` | Витрина компонентов и токенов |
| `_ds/industry-.../` | Дизайн-система: `styles.css`, `_ds_bundle.js`, `_ds_manifest.json`, правила в `readme.md`, линт-конфиг `_adherence.oxlintrc.json` |
| `styles.css` | Токены и классы компонентов — источник правды по внешнему виду |
| `assets/`, `screenshots/` | Изображения и снимки экранов |
| `uploads/cone-crusher-chamber.html` | Расчёт профиля камеры дробления |

Открывается как статика: `.dc.html` в браузере, стили подтягиваются из `styles.css`.

## Чего здесь нет

Папка `uploads/` при переносе исключена — 35 МБ вставленных скриншотов и `.docx` с описанием задачи. Из неё перенесён только `cone-crusher-chamber.html`. Оригинал целиком — в локальной папке `Уралмаш React`.

## Демо-доступы

В прототипе захардкожены тестовые пользователи (`ivanov/1234`, `admin/admin`) — это мок для демонстрации входа, не настоящие учётные данные.
