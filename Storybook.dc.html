Атомы — Поля ввода
Один класс .input для text/date/select-триггера. Плавающая подпись — для полей без готового значения по умолчанию (название проекта, заказчик).

Единый компонент SelectBox: одиночный/множественный выбор, поиск, заголовок с доп.действием (шестерёнка), футер («+Добавить»), группы-заголовки.
